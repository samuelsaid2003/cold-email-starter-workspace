# Business context

The business-interview skill fills this file. Every agent working in this workspace reads it before a cold email task.

How to read it:
- Text under each heading is the owner's own answer, lightly tidied.
- **(guess, confirm)** marks something the agent inferred and the owner has not confirmed. Don't rely on it in copy or replies.
- **(from source: ...)** marks something taken from a document, site or export the owner shared, with where it came from.
- **Not answered yet** means the question hasn't been asked. **Skipped** means the owner chose not to answer. **Doesn't apply** means the owner said it isn't relevant.

## 14. Standing rules

These apply to every task in this workspace.

- Only use real links. Never make up a URL, booking link or case study link. If a link isn't in this file or given by the owner, ask for it.
- Flag guesses. Mark anything inferred, not confirmed, as **(guess, confirm)**, and don't put a guess in outreach until the owner confirms it.
- Ask for an export when a source is blocked. If a website, file or tool can't be read (login, paywall, error), say so and ask the owner for an export or a paste. Don't fill the gap from memory.
