# Meetings

- `offered-times.md`: every time offered to a lead, held until booked, declined or released, so two leads never get the same slot.
- `meetings.md`: every booked meeting and what happened: held, no-show, cancelled or moved.
- `briefs/`: the call prep brief for each meeting, named `YYYY-MM-DD-company.md`.

The booking-and-show-up skill keeps the two logs. The call-prep skill writes the briefs.
